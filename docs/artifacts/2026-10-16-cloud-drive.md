## How to Apply

These are Kysely TypeScript migrations. They are **created but not yet executed**
(they change database state and require explicit human approval + a DB backup).

Apply with the project's migration runner, e.g.:

```bash
# from repo root
pnpm --filter server migration:up
# or the equivalent kysely migrator command configured in the server app
```

Rollback: run the migrator `down` / `migrateTo` to revert to the previous
version. Each migration also defines `down(db)` that drops its table(s).

> Safety gate: applying migrations mutates the database. Do NOT run `--execute`
> without a confirmed backup and a reviewed change window.
